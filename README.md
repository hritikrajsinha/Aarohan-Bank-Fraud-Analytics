# Aarohan Bank Fraud Analytics

A fraud detection and analytics project focused on identifying suspicious banking transactions using data engineering and machine learning on Databricks.

## Project Structure

- `data/` — Raw and processed datasets
- `notebooks/` — Analysis and modeling notebooks
- `pipelines/` — Data processing pipelines
- `models/` — Trained ML models and artifacts

## Getting Started

1. Clone this repository
2. Open in Databricks workspace
3. Set up your compute and warehouse resources
